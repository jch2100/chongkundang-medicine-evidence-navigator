# 데이터 교정 기록

## 운영 원칙

- 공식 원문 링크가 확인되지 않은 값은 추정하지 않는다.
- 적응증, 성분, 용량, 부작용은 원문 확인 없이 요약하거나 확정하지 않는다.
- 변경 이력은 최근 5년 범위에서 게시일·변경 유형·원문 링크를 남기고, 전후 문구는 원문에서 확인하게 한다.
- 수정은 `오류 발견 → Issue → 근거 링크 확인 → 2인 검토 → 데이터 수정 → 자동 검증 → 공개` 순서로 남긴다.
